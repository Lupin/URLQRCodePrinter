# Archives — explorations visuelles de la fiche Chrome Web Store

Ces fichiers ne sont **pas utilisés par la construction** ni par `npm run store`.
Ils sont conservés comme historique des choix graphiques : propositions écartées,
variantes sans texte, maquettes de la fiche.

| Élément | Ce que c'est |
|---|---|
| `alternatives/` | Propositions de petites images promotionnelles (440 × 280) et essais successifs |
| `Screenshot 2026-09-25 at 10.22.44.png` | Capture de travail du 25 septembre 2026 |
| `Untitled.af` | Source Affinity Designer de la première piste de visuel |
| `promo-440x280-2026.png` | Ancienne version de la petite image |
| `visuels-mise-a-jour/` | Visuels préparés pour la mise à jour de la fiche (FR/EN) |

Les visuels **retenus** restent dans `store/promo/` : `promo-440x280.jpg` et
`marquee-1400x560.jpg`. `npm run store` les copie dans `dist/store/`.

Archivé le 23 novembre 2026, lors du nettoyage du dépôt. L'historique Git des
fichiers suivis est conservé ; les fichiers non suivis de `alternatives/` et
`visuels-mise-a-jour/` sont désormais dans l'archive pour ne pas rester en vrac
à la racine de `store/`.
